S1Lua installation
==================

1. Install MelonLoader and S1API for the same Schedule I runtime as this archive.
2. Extract this archive into the Schedule I game folder.
3. Start the game once and look for the S1Lua loaded message.
4. Open Mods/S1Lua/MyFirstMod and rename mod.lua.example to mod.lua.
5. Edit mod.lua in a text editor, then restart the game.

Do not mix Mono and IL2CPP release archives.

Editor/s1lua.lua is optional autocomplete metadata for Lua Language Server.
Documentation: https://github.com/ifBars/S1Lua
